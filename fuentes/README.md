# Fuentes reales anonimizadas

Esta carpeta está reservada para fuentes textuales reales, anonimizadas y publicables. Los PDF originales del curso, papers o casos con derechos de autor no deben copiarse completos al repositorio público.

## Criterios de aceptación

Una fuente puede usarse en una corrida real si cumple estas condiciones:

- fue usada efectivamente por el agente;
- no contiene nombres, correos, cuentas, legajos ni identificadores personales innecesarios;
- no contiene claves, datos bancarios, datos médicos ni información laboral confidencial;
- puede publicarse o compartirse con el evaluador;
- conserva suficiente evidencia para reconstruir la decisión del agente;
- está en un formato admitido por la versión actual: `.txt`, `.md`, `.csv`, `.json`, `.html` o `.htm`.
